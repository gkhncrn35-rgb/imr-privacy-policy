Privacy Policy

IMR Intelligence Studio

Last updated: October 11, 2026

1. Overview

IMR Intelligence Studio is a private, single-user Windows 11 application developed for analyzing and managing Pinterest marketing activities for the IMRArtAndDesign Etsy shop. The application is not publicly distributed.

2. Information Accessed

With the account owner's authorization, the application may access Pinterest account information, Pins, boards, impressions, saves, clicks, and engagement analytics.

3. Use of Information

Data is used exclusively to analyze organic marketing performance, generate private reports, and improve content decisions. We do not sell Pinterest data or share it for third-party advertising.

4. Storage and Security

Application data is intended to be stored locally on the account owner's computer. Authentication tokens will be protected using secure storage mechanisms.

5. Data Retention and Deletion

Information is retained only as needed for application functionality. The owner can revoke Pinterest access and delete locally stored application data.

6. Third-Party Services

The application uses the Pinterest API and follows applicable Pinterest developer policies.

7. Policy Updates

This policy may be updated when application functionality or data handling practices change.
